# Proposal: Liquid Glass icon for forge-hello-world

Flat, square layers (no rounded square: the system applies the shape and the glass).
To try it, copy the two SVG files into an `icon/` folder next to `App.tsx` of the app:

```
icon/background.svg
icon/foreground-1.svg
```

then run `forge build`. This is a proposal only; nothing in the app repository was changed.
